# RM75 纯 PPO 随机位姿任务设计

## 目标

在不破坏 `UR5-v0`、`RM75-v0`、`RM75Approach-v0` 和 V9 权重兼容性的前提下，新建 `RM75Pose-v0`。策略从头学习随机目标位置和随机切入方向，最终判据为位置误差小于 5 cm、方向误差小于 20 度，并连续保持 5 个控制步。

## 固定接口

- 旧 `RM75Approach-v0` 恢复并固定为 34 维观测、7 维动作；删除 40 维相对观测开关和兼容扩展逻辑。
- 新 `RM75Pose-v0` 使用 20 维确定性归一化观测：7 个关节位置、7 个关节速度、3 个末端到目标的位置误差、3 个工具轴到目标方向的旋转向量。
- 新任务仍输出 7 维 `[-1, 1]` 归一化关节增量，环境将每维动作缩放为最大 `0.05 rad` 的目标关节增量。
- 新任务固定回合上限为 400 个控制步，不使用自动课程学习。

## 奖励

用两个关键点同时描述位置和切入方向：末端原点及沿当前工具轴 0.15 m 的点，对应目标原点及沿目标方向 0.15 m 的点。两个对应点距离的均值是 `keypoint_error`。

每步奖励只包含：关键点误差、近目标非线性误差、动作幅值、相邻动作变化、成功奖励和碰撞惩罚。新任务不复用旧课程奖励、进度奖励、里程碑或超时惩罚。

## PPO

- 算法仍是同一份 CleanRL PPO，不加入 IK 控制、示范学习、残差控制或 HER。
- 新策略网络为 `20 -> 256 -> 128 -> 64 -> 7`，价值网络为 `20 -> 256 -> 128 -> 64 -> 1`，激活函数为 ELU。
- 旧环境默认使用原来的两层 64 单元 Tanh 网络；可视化从权重结构自动判断网络配置。
- 提供唯一的新训练脚本，从头训练 2,000,000 环境步；正式运行由用户执行。

## 验收

- V9 的 34 维权重可以继续被 `Scripts/visualize_agent.py` 加载。
- 新环境 reset/step 返回 20 维有限观测和 7 维动作接口。
- 新奖励在关键点误差更小时更高，来回摆动因动作变化惩罚不能获利。
- 连续满足 5 步才终止成功，碰撞立即终止。
- 只运行语法检查、相关单元测试和极短的无跟踪冒烟测试，不启动正式训练。
